# Setting up Nookal

To get Nookal set up there are three steps:

1. [Create a permissions group for Effra](#create-a-permissions-group-for-effra)
2. [Grant Effra access to Nookal](#grant-effra-access-to-nookal)
3. [Enable Nookal's Invoices & Quotes Upgrade Extension](#nookal-upgrade)

## Create a permissions group for Effra

1. On the menu at the top of the screen, click **Setup**
2. In the **Users** section, click **Permissions**
3. At the bottom right of the screen, click **Create New Group**
4. Enter a title for the new group (e.g. Effra) and select continue
5. The new permissions group will now appear in the table, and you are ready to select the items Effra requires. These are:

| Permissions Sub-Heading | Permissions Item | View or Edit? |
| --- | :-- | :-- |
| Features | Services | View |
| Features | Permissions | View |
| Clients | Cases | View |
| Clients | Details | View |
| Clients | Accounts | Edit |
| Setup | Invoices | Edit |
| Setup | Case Titles | Edit |
| Setup | Integrations and API Keys | Edit |
| Integrations | API Keys | Edit |
| Administration | Pay Invoices | Edit |
| Invoices | Credits | Edit |
| Reports | Invoices Report | View |

## Grant Effra access to Nookal

Now, you can create a new user for Effra.

1. On the menu at the top of the screen, click **Setup**
2. In the **Users** section, click **Staff**
3. At the bottom right of the screen, click **Create Staff Member**
4. Give the new user a name that's memorable to you
5. Set the **Position** and **Discipline** to anything you would like, e.g. Accounts and Administrator
6. Set the **Status** to **Active**
7. For the **Permissions**, select "Effra", or whatever you named the permissions group that you just created.
8. Set **Locations** to **All Locations**, unless you only want Effra to support billing at some of your locations
9. Set the email address to [**robot@effra.io**](mailto:robot@effra.io)
10. Click **Create Staff Member**

## Enable Nookal's Invoices & Quotes Upgrade Extension {#nookal-upgrade}

Lastly, you should enable Nookal's latest invoicing feature.

1. On the menu at the top of the screen, click **Setup**
2. In the **Extensions** section, click **Advanced**
3. Ensure the toggle for **Nookal's Innovation Hub** is switched on and click **Configure** beneath it
4. Within the **New Innovations** tab, use the toggle to switch on the **Invoices and Quotes Upgrade**
