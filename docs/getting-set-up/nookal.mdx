# Setting up Nookal

To get Nookal set up there are two steps:

1. [Grant Effra access to Nookal](#grant-effra-access-to-nookal)
2. [Set up payment types](#set-up-payment-types)

## Grant Effra access to Nookal

Granting Effra access to Nookal is as simple as adding a new user, and securely sharing the login details with us.

1. On the menu at the top of the screen, click **Setup**
2. In the **Users** section, click **Staff**
3. At the bottom right of the screen, click **Create Staff Member**
4. Give the new user a name that's memorable to you
5. Set the **Position** and **Discipline** to anything you would like, e.g. Accounts and Administrator
6. Set the **Status** to **Active**
7. For the **Permissions**, select "Owner". This allows us to create an API key so we can pull invoice information into Effra
8. Set **Locations** to **All Locations**, unless you only want Effra to support billing at some of your locations
9. Set the email address to **robot@effra.io**
10. Click **Create Staff Member**

## Set up payment types

Effra will record payments back into Nookal when your invoices are paid. You need to set up custom payment types so that it's clear which payments have been created by Effra.

1. On the menu at the top of the screen, click **Setup**
2. In the **Practice** section, click **Invoicing**
3. Select **Create Payment Method**
4. Enter "Effra Insurer Payment" in both text boxes
5. Click the save button6. Repeat this for "Effra patient payment"
