# Setting up TM3

To get TM3 set up there are two steps:

1. [Grant Effra access to TM3](#grant-effra-access-to-tm3)
2. [Set up payment types](#set-up-payment-types)

## Grant Effra access to TM3

Granting Effra access to TM3 is as simple as adding a new user.

1. From the top right of the screen click on your **user icon** and then select **Settings**
2. Click **Setup** and then **Users**
3. Click **Add**
4. Add the applicable locations to the new user and give them a name that's memorable to you
5. For **User Level** select **Practice Administrator**
6. Set the email address to **robot@effra.io**
7. Click **Create**

## Set up payment types

Effra will record payments back into TM3 when your invoices are paid. You need to set up custom payment types so that it's clear which payments have been created by Effra.

1. From the top right of the screen click on your **user icon** and then select **Settings**
2. From the menu that appears on the left, select **Configuration**
3. Select **Custom lists**
4. Under the **Please select a lookup** drop down select **Payment Types**
5. In the **Type new list value** enter "Effra insurance payment" then click **Add to List**
6. Repeat this for "Effra patient payment"
