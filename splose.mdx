# Setting up Splose

To get Splose set up there are two steps:

1. Grant Effra access to Splose
2. Set up payment methods

## **Grant Effra access to Splose**

1. In the top right, click **Settings**
2. In the left sidebar menu, click **Users**
3. In the top right, click **Invite users**
4. Complete the required fields in the following way:
   1. First Name: Effra
   2. Last Name: Ltd
   3. Email: [robot@effra.io](mailto:robot@effra.io)
   4. Role: Practice Manager
5. Click **Send**

## **Set up payment methods**

1. In the top right, click **Settings**
2. In the left sidebar menu, click **Payments**
3. Scroll to the bottom, click **Add payment method**
4. Complete the required field in the following way: 
   1. Name: Effra Patient Payment
5. Tick the box marked **Active**
6. Click **Create**
7. Repeat to create another payment method
   1. Name: Effra Insurer Payment
